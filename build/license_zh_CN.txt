1. 项目身份与许可证

2. 本地优先与 Online Host

桌面服务默认仅监听 127.0.0.1 等本机回环地址。仅安装软件不会自动让你的电脑、文件或 API 可被互联网访问；Host 开启时，本地调用方仍需有效 Gateway Key。

Online Host 是单独且需要明确启用的功能，需要兼容平台和可工作的 Relay。本仓库当前的平台是本地开发预览，尚未部署公共 Relay。如果你通过端口转发、反向代理、隧道、VPN、容器或其他方式自行暴露接口，你应负责 TLS、身份认证、访问控制、限流、审计、密钥管理、隔离、合规和安全事件处置。

3. 数据与网络通信

软件可能处理应用设置、Gateway Key 哈希及加密副本、模型和权限策略、任务状态、调用记录、Token 与延迟统计、临时附件和诊断信息。调用模型时，提示词、经授权的项目内容、文件、图片、任务参数和结果可能经本地 Coding Agent 运行环境发送至你使用的模型服务；对应服务的条款和隐私政策也适用。

ccc_live_... Gateway Key 是 Agent Gateway 凭据，不是 OpenAI API Key，必须妥善保密。检查更新可能访问 GitHub Releases。本项目不包含广告跟踪、用户画像或第三方崩溃遥测。存储、保留和删除详情见仓库中的 PRIVACY.md。

4. 文件权限与自动化

请使用最低必要权限。Coding Agent 可能在授权范围内读取、创建、修改或删除内容。重要数据应先备份，高风险操作应人工检查。AI 输出可能不完整或不准确，不得作为医疗、法律、金融、生命安全、关键基础设施等高风险决策的唯一依据。
