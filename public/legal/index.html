本地优先与 Online Host

桌面服务默认仅监听 127.0.0.1 等本机回环地址。安装软件本身不会自动让电脑、文件或 API 可被互联网访问。Online Host 需要登录兼容平台、可工作的 Relay，并由用户主动启用。本仓库当前平台仍是本地开发预览，尚未部署公共 Relay。

如果你自行通过端口转发、反向代理、隧道、VPN、容器或其他方式暴露接口，你应负责 TLS、身份认证、访问控制、限流、审计、密钥管理、网络隔离、合规和安全事件处置。

02

隐私说明摘要

Agent Gateway 是本地优先软件。桌面模式把设置、Gateway Key 哈希及加密副本、用量统计和偏好保存在应用数据目录；临时附件和无项目工作区在任务结束或到期后清理。项目代码不包含广告跟踪、用户画像或第三方崩溃遥测。

模型调用会把你提交的提示词和授权内容交给本机 Codex 运行环境及相应模型服务商。主动检查更新会访问 GitHub Releases。公开部署或 Relay 的运营者在技术上可能接触经过其服务器的内容，因此不要向不可信运营者发送敏感数据。

删除本地数据前，应先删除 Gateway Key、取消任务并完全退出程序，再按照仓库 PRIVACY.md 中的路径处理应用数据和临时目录。卸载程序不会删除模型服务商、GitHub、反向代理或备份中保存的数据。

03

安全说明摘要

默认桌面边界是一个受信任的 Windows 用户和仅监听回环地址的本地服务。Gateway Key 用于授权调用，但不是完整的公网多租户隔离机制。公网部署需要额外的 TLS、强身份、最小权限、租户隔离、限流、审计、密钥管理、备份安全和出口控制。

泄露的 Gateway Key 应立即在应用中删除；模型 API Key、Codex 凭据或加密密钥应在来源处轮换。不要在公开 Issue 中发布密钥、私人路径、提示词、附件或可直接利用的漏洞细节。

漏洞请通过 GitHub Security Advisories 私密报告。一般问题和删除请求使用 GitHub Issues。

English summary

Agent Gateway is an independent, community-maintained open-source project operated by individual maintainers, not an incorporated company or an OpenAI product. The desktop service is local-first and listens on loopback by default. Online Host is separate and explicit; the current repository platform is a local development preview without a public Relay.

The application may store settings, Gateway-key verification data and encrypted copies, usage aggregates, and temporary task data locally. Model requests may send prompts and authorized files to the coding-agent runtime and selected model provider. The project contains no advertising trackers, profiling, or third-party crash telemetry.

Use least privilege, protect ccc_live_... keys, back up important files, and do not use the software for unauthorized or unlawful activity. The software is provided as is and as available to the maximum extent permitted by law.
